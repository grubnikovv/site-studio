# Site Studio — правила работы

Студия делает премиальные сайты и Telegram-ботов для малого и среднего бизнеса в России (продажи через Kwork и напрямую). Полный цикл: исследование референсов → дизайн → качественный код фронтенда и бэкенда → запуск.

## Как общаться с владельцем

- Только по-русски, коротко и по шагам. Одно сообщение — один понятный шаг. Длинные простыни путают.
- Владелец работает **только с телефона**, кодом не владеет. Не давать действий, требующих компьютера. Всё, что нужно сделать руками, — пошагово, с готовым текстом для копирования.
- Результат показывать ссылкой, которая открывается с телефона без VPN: GitHub Pages `https://grubnikovv.github.io/site-studio/<папка>/` (сборка: `python3 scripts/build_docs.py`, папка `docs/`, ветка `claude/low-code-business-ideas-0dr8l2`).

## Процесс

1. **Референсы.** Перед дизайном изучить, что делают лучшие сайты в нише (Awwwards, Godly, Land-book, Lapa Ninja, One Page Love, SiteInspire, Codrops). Берём идеи и приёмы, не копируем чужой дизайн.
2. **Концепция.** Одна «вау»-анимация, связанная с сутью бизнеса (иней тает на окне, блик на лаке, разрез профиля), а не набор случайных эффектов. Всё вокруг — спокойно и аккуратно.
3. **Продающая структура.** Цена «от» и оффер на первом экране, акции, калькулятор или квиз, блоки доверия, заявка в 1–2 касания, кнопка записи на телефоне.
4. **Проверка перед показом:** скриншоты ПК (1440) и телефона (390), все страницы; без пустых зон, без вылезающего текста, без горизонтальной прокрутки, без ошибок в консоли.

## Стандарты кода

- **Скорость прежде всего.** Чистый HTML/CSS/JS без фреймворков и тяжёлых библиотек, если они не нужны. Цель — Lighthouse 90+ на телефоне.
- Анимации — CSS transform/opacity, Canvas, IntersectionObserver, requestAnimationFrame с троттлингом прокрутки. Никаких анимаций width/top/left. Уважать `prefers-reduced-motion`.
- Изображения: WebP/AVIF, правильные размеры, `loading="lazy"`, `width/height`, без тяжёлых видео на первом экране.
- Шрифты: максимум 2–3 семейства, `display=swap`, `preconnect`.
- Семантическая разметка, доступность (фокус, подписи полей, контраст), мета-теги и микроразметка для SEO, `robots noindex` на демо.
- Код простой и читаемый: без лишних абстракций, понятные имена, комментарии только там, где неочевидно.
- **Бэкенд:** формы и калькуляторы шлют заявки в Telegram через серверный обработчик (PHP на хостинге клиента или serverless-функцию) — токен бота никогда не хранится во фронтенде. Валидация на сервере, защита от спама (honeypot, лимиты), согласие по 152-ФЗ.

## Коммерция

- Админку не обещать в дешёвых заказах. Альтернатива — цены в Google Таблице или правки за абонентскую плату.
- Индивидуальное демо — только под заказы от 20–30 тыс. ₽. На мелкие — отклик + портфолио.
- Приоритетная ниша для прямых продаж — грузовой транспорт: грузовые автосервисы, шиномонтажи, запчасти, перевозчики, эвакуаторы.

## Структура репозитория

- `templates/` — шаблоны ниш (детейлинг, кофейня, стоматология, кухни, фитнес).
- `demos/` — демо под конкретные заказы.
- `docs/` — публичные версии для GitHub Pages (генерируются скриптом).
- `scanner/`, `.github/workflows/scan.yml`, `jobs/`, `results/` — поиск заказов и компаний через GitHub Actions (результаты зашифрованы).
