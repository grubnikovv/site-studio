# Сервер сайта «М.А»: бот Telegram

Что делает:
- принимает с сайта новые записи и отмены (`api.php`);
- бот `@ma_mihaylovka_bot` присылает клиентке подтверждение записи с кнопками «Подтверждаю» и «Перенести» (`tg.php`);
- напоминает за 2 дня, за 2 часа и о коррекции через 3 недели (`cron.php`, каждые 10 минут);
- присылает Марине уведомления: новая запись, отмена, подтверждение, просьба перенести, брони обучения и сертификаты;
- через 3 года удаляет старые записи (срок по политике конфиденциальности).

Нужно: хостинг с PHP 8 и SQLite. HTTPS не обязателен: без него бот работает через `poll.php` (опрос раз в минуту).

Сейчас тест на Timeweb: выкладка — GitHub Actions «Выложить сайт М.А» (секреты BOT_TOKEN, ADMIN_KEY, FTP_PASSWORD), в Crontab каждую минуту: `php ~/public_html/server/poll.php` (он же шлёт напоминания).

## Установка (один раз)

1. Загрузить папку `server` на хостинг рядом с сайтом.
2. Скопировать `config.sample.php` в `config.php` и заполнить:
   - `bot_token` — токен от @BotFather;
   - `admin_key` — длинная случайная строка (от 16 символов);
   - `site_url` — адрес сайта;
   - `allow_origin` — адрес сайта (чтобы события принимались только с него).
3. Открыть в браузере `https://САЙТ/server/setup.php?key=admin_key` — подключится вебхук, появится ссылка для Марины.
4. Марина открывает эту ссылку со своего Telegram и нажимает «Старт» — теперь уведомления приходят ей.
5. В панели Beget → «Планировщик задач (cron)»: каждые 10 минут `php ~/САЙТ/public_html/server/cron.php`.
6. На сайте в `index.html` вписать `var API = "/server/api.php"`.

Токен и `config.php` в репозиторий не попадают (см. `.gitignore`).
